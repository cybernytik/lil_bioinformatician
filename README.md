# lil_bioinformatician
## Overview
'lil_bioinformatician' is a study project that exists to help begginers in bioinformatics, including me, to learn and understand how bioinformatics tools work. This project names so because of the legend in my study group about 6 levels of bioinformaticians due to the number of courses we will have in our Uni.
